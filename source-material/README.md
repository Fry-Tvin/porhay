# Исходники от заказчика

Сырьё, из которого собирались страницы сайта: присланные фото и сохранённые
страницы со старого Taplink. Здесь оно лежит как архив — **в сборку сайта
не входит** и на `порхай.рф` не публикуется.

Почему не в `porhai-new/`: деплой (`.github/workflows/deploy-pages.yml`)
копирует на сайт все `porhai-new/*.html`, поэтому сохранённая
Taplink-страница, лежащая там, уехала бы в прод отдельным адресом. Плюс
`porhai-new/content/` — это вход для `optimize_images.py`, и файлы вроде
`1.png` или `а.png` там только путали бы поиск исходников по имени.

| Папка | Что внутри |
|---|---|
| `taplink-besplatnoe-poseschenie/` | Сохранённая страница «Бесплатное посещение» с Taplink (`taplink.cc/porhay_vladivostok/p/1129645/`) со всеми ассетами. По ней собрана скрытая страница `/podarok`. |
| `torty/` | Исходные фото тортов. Обработанные версии — `porhai-new/content/tort-*.png` → `assets/img/tort-*.webp`, страница `/torty`. |
| `pinyaty/` | Исходные фото пиньят. Обработанные версии — `porhai-new/content/pinyata-*.jpg` → `assets/img/pinyata-*.webp`, страница `/pinyaty`. |

Файлы перенесены как есть, имена не менялись — только названия папок
приведены к латинице, чтобы не мучиться с экранированием в git и shell.

Сохранённая Taplink-страница тянет сторонние скрипты (Google Tag Manager,
рекламные теги Яндекса) — открывать её локально стоит только осознанно,
и уж точно не публиковать.
